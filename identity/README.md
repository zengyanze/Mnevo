# 身份层（identity/）

身份层 = 常驻注入每个会话的"你是谁"：**persona**（沟通风格/背景）、**values**（价值观/决策偏好）、**goals**、**active threads**（进行中的事）。形态 = markdown + git，修改即提交，历史即审计。

## 布局

- `live/` —— 真身，**不入库**（见根 .gitignore）：本仓库未来公开，个人身份内容不得进入公开历史；
- 本 README 内的骨架样例 —— 可入库，作为结构参考：

```markdown
# live/persona.md      我是谁、说话风格、背景要点（个人事实，非公司信息）
# live/values.md       决策偏好：例如"实用主义优先于技术洁癖""成本敏感"
# live/goals.md        中期目标（季度粒度）
# live/threads.md      活跃上下文：进行中的项目、未闭环事项（每条含最后更新日期）
```

## 铁律

1. 管家对身份层只有**提案权**（diff），人工确认后生效——"你是谁"不许机器自作主张；
2. active threads 里过期条目归档不删除（谱系优先于破坏性清理）；
3. 种子来源：从 pi 现有记忆提炼个人部分、剔除工作载荷（v0.1 任务 2 收尾项）——产出为**提案稿**，人工过目后才进 `live/`。
